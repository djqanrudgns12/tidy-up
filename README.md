## 실행과 검사

Node24 환경에서 확인했습니다. Windows PowerShell:

```powershell
npm.cmd ci
npm.cmd run check:handoff
npm.cmd run dev -- --port 5173
```

브라우저에서 http://127.0.0.1:5173/ 을 엽니다. 이름/캐릭터와 분류 활동 뒤9개 공간 중 하나를 선택합니다. 기본8개에 물건을3개까지 더할 수 있습니다. 끌기 또는 목록 선택 후 놓을 위치를 누르는 방식으로 정리합니다.

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run check:assets
node scripts/serve-dist.mjs
```

에셋 검사127/127·누락0이 정상입니다. 로컬 빌드는 http://127.0.0.1:4173/Cleaning/ 에서 확인합니다. 이 명령은 외부 게시를 하지 않습니다.

배포용은 dist 전체이며, 수정·재빌드에는 프로젝트 전체가 필요합니다. HTML 하나를 직접 여는 방식은 지원하지 않습니다. 원본 PDF와 원화는 sample/artwork에 보존하고 배포 폴더에는 넣지 않습니다.

## 검수

- 개발 서버 ?review는 수납·꺼내기·포개기·걸이·작은 밀림을 확인합니다.
- ?responsive는 다섯 CSS 화면 크기의 앱을 보여 주며 실제 터치·가상 키보드·저장 검수를 대신하지 않습니다.
- ?wardrobe-layout, ?final-layout=living-room, ?final-layout=shoe-cabinet은 새3공간의42조합·모션·복원·썸네일을 확인합니다.
- 개발용 검수 화면은 배포 빌드에서 제외합니다.

이름·활동은 이 브라우저의 로컬 저장소에 보관하며 마지막 갱신2시간 뒤 다시 읽을 때 만료 처리합니다. 서버·로그인·외부 분석·자동 평가가 없습니다. 결과는 정리 전과 청소 후를 담은 PNG1984×848입니다.
