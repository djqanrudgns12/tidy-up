# 내가 정리하는 생활 공간

초등학교5학년 실과의 정리 정돈·청소를 연습하는 웹 활동입니다.

**다른 컴퓨터에서 이어서 작업:** 변경 파일과 원화·PDF·검수 자료까지 커밋하고 원격 저장소에 반영한 뒤, 새 컴퓨터에서 저장소를 clone합니다. [handoff.md](handoff.md)를 시작점으로 읽습니다. [작업 위키](docs/wiki/README.md)에 현황·의존 관계·원화·검수 근거가 연결되어 있으며, 프로젝트를 열고 `이어서 해`라고 요청하면 이 순서로 재개합니다. 별도 ZIP은 필요하지 않습니다.

**최신 인계:** [중단점과 바로 다음 작업](docs/wiki/DESKTOP_HANDOFF_2026-09-16.md)에 원화107개·검수 대기15개·미생성5개 및 옷장 진행 코드를 기록했습니다. 현재 변경과 새 파일은 별도 커밋·푸시 전입니다.

**개발 중:** 현재 내 책상·수납장·사물함·도서관·공부 책상·침실6개 공간에서 전체 활동을 사용할 수 있습니다. 나머지3개 공간과 남은 추가 시점 원화는 제작·통합 중입니다. 최신 상태는 [위키 상태표](docs/wiki/STATUS.md)와 [검수 기록](docs/wiki/VERIFICATION.md)을 따릅니다.

전체 완성 여부와 남은 검사 항목은 [완료 조건 점검](docs/COMPLETION_AUDIT.md)에 구분했습니다. 현재 테스트67개와 빌드가 통과했지만, 전체 에셋과 실기기 검수는 완료되지 않았습니다.

## 실행

Node24 환경에서 확인했습니다. Windows PowerShell에서는 다음 명령을 사용합니다.

```powershell
npm.cmd ci
npm.cmd run dev -- --port 5173
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다. 이름/별명과 캐릭터를 고르고, 분류 활동을 한 뒤 내 책상 또는 수납장을 선택합니다. 기본8개에 물건을3개까지 더할 수 있습니다. 물건을 끌거나 목록에서 고른 뒤 놓을 위치를 눌러 정리합니다.

## 검사와 로컬 빌드 확인

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run check:assets
node scripts/serve-dist.mjs
```

현재 전체 에셋 검사는 미반영·미생성 파일 때문에 실패합니다. 최신 수량은 [자동 상태표](docs/wiki/STATUS.md)를 확인합니다. 실패를 생략해 전체 완성으로 처리하지 않습니다. 로컬 빌드는 `http://127.0.0.1:4173/` 또는 `/Cleaning/`에서 확인할 수 있습니다. 실제 게시를 수행하는 명령은 아닙니다.

`dist`는 여러 파일로 구성된 정적 사이트입니다. 웹서버에 올릴 때는 폴더 내용 전체가 필요합니다. 이후 수정·재빌드에는 이 프로젝트 전체를 보관합니다. HTML 한 파일을 직접 여는 방식은 지원하지 않습니다.

## 배치 검수

- 개발 서버의 `?review`: 수납·꺼내기·포개기·가방걸이·작은 밀림을 프레임별 확인하고 기본8개 썸네일을 만듭니다.
- 개발 서버의 `?responsive`: 다섯 CSS 화면 크기에서 실제 앱을 확인합니다. 실기기의 터치·가상 키보드·저장 검수를 대신하지 않습니다.
- 개발 서버의 `?cabinet-review`: 바구니 앞면의 구멍과 살을 분리해 합성하는지 확인합니다. 기존 물병을 가림 시험에만 사용하며, 수납장 활동의 물건 배치 예시는 아닙니다.
- 모든 개발용 검수 화면과 초기 Proof는 배포 빌드에서 제외합니다.
- [AGENTS.md](AGENTS.md), [접촉 검수 기준](docs/PLACEMENT_REVIEW.md), [PRD](PRD.md)를 읽고 이어서 작업합니다.

이름·활동은 이 브라우저의 로컬 저장소에 보관하며 마지막 갱신2시간 뒤 다시 읽을 때 만료 처리합니다. 서버·로그인·외부 분석·자동 평가가 없습니다. 결과는 정리 전과 청소 후를 담은 PNG1984×848입니다.

원본 PDF와 원화는 각각 `sample`, `artwork`에 보존하며 배포 폴더에 넣지 않습니다.
