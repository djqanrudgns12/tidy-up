# 물건 배치와 접촉 검수

2026-09-16 사용자 추가 지시에 따른 필수 구현 기준. PRD v2.1 및 AGENTS.md와 함께 읽는다. 자연스러움은 기능 완성과 별도로 실제 화면에서 검수한다.

## 물건 자세

| 자세 | 위치·방향 | 검수 |
|---|---|---|
| 눕힘 | 상판·바닥 면의 두 축 안에서 회전 | 책·공책·납작한 문구가 바닥 원근과 맞는지 |
| 세움 | 밑면을 지지면에 접촉, 화면 회전 제한 | 물병·가방이 떠 있거나 넘어져 보이지 않는지 |
| 책장 | 책의 밑면을 선반 높이에 맞추고 가로 위치 선택 | 책 제목·높이·선반 앞턱의 가림 |
| 걸기 | 손잡이/옷걸이의 걸리는 지점을 실제 걸이에 맞춤 | 끈·고리의 위치와 그림 방향 |

## 완료 판정

보관 장소와 지지면이 맞고, 물건의 바닥 경계 전체가 지지면 안에 있어야 한다. 상판 밖으로 걸치기, 가구 발을 관통하기, 보통 물건끼리 겹치기는 허용하지 않는다. 미관·간격을 점수로 계산하지 않으며 허용 면 안에서 여러 배치가 가능해야 한다.

## 첫 책상 배경 검토

생성된 배경은 계획 좌표보다 수납칸이 오른쪽에 있고 낮다. 책은 책상 위·책상 속에서는 눕힌 자세로 보여야 한다. 정면 책 그림을 그대로 세워 넣으면 높이가 맞지 않는다. 가방걸이는 책상 오른쪽 프레임에 한 개 있으므로 실제 걸리는 위치를 사용한다.

## 검수 기록

- 대표 장면의 실제 렌더링·드래그 후 놓기·최종 PNG를 같은 기준으로 비교한다.
- 실제 아트와 최종 좌표가 확정되면 맵별 지지면·가림 면·예외를 이 문서에 기록한다.
- 자동 검사는 경계·접점·금지 회전을 확인한다. 사람이 보는 자연스러움은 실제 화면과 PNG로 별도 검수한다.

## 접점과 원근

- 원화의 실제 알파 경계 비율을 유지한다. 물건마다 정한 실제 크기 범위 안에 넣고, 수납할 때만 작게 만들지 않는다.
- 눕힘은 물건 면 안에서 회전한 뒤 지지면으로 투영한다. 그림과 충돌 경계에 같은 변환을 적용한다.
- 내 책상의 깊이 선에서 측정한 소실점은 논리좌표(518,-312)다. 물건의 위치에 따라 옆선 방향을 보정한다. 다른 배경에 이 값을 복사하지 않는다.
- 세움은 밑면, 걸기는 손잡이 안쪽의 받쳐지는 곳을 기준으로 한다. 가방걸이는 끝 돌기와 오목한 받침을 구분한다.
- 현재는 고정 카메라의 2.5D 장면이다. 시점을 돌려 보거나 일반적인3D 물리 시뮬레이션을 제공하지 않는다. 다른 면이 보이는 물건은 별도 원화를 제작한다.

## 작은 겹침과 포개기

1. 가장자리에서24 논리px 이내인 놓기는 같은 면 안쪽에 지지되도록 보정할 수 있다.
2. 일반 물건과 부딪치면 분리 가능한 방향을 가까운 순서로 찾는다. 그 위치에서36 논리px 안에서 **놓던 물건만** 이동한다. 기존 물건을 연쇄적으로 밀거나 줄 세우지 않는다.
3. 빈자리가 없거나 벽·가구를 넘어야 하면 확정하지 않는다. 거부된 드래그는 짧은 복귀 동작으로 원래 자리에 돌아온다.
4. 책·파일은 윗물건 전체가 아래 표지 안에 들어오는 두 겹만 허용한다. 아래 물건 하나에 윗물건은 하나뿐이다. 아래 책은 윗책을 먼저 옮겨야 꺼낼 수 있다.
5. 저장 복원·정리 완료·이동 확정은 같은 전체 배치 검사로 관통과 잘못된 포개기를 거부한다.
6. 실제 그림을 누르면 가장 위에 그린 물건부터 선택한다. 투명 여백을 제외하며, 작은 물건에는44 CSS px 크기의 보조 선택 영역과 DOM 목록을 제공한다.

## 넣고 꺼내는 동작

- 입구와 안쪽 받침 면을 구분한다. 강조·탭 판정은 입구, 확정 위치·최종 렌더링은 안쪽 면을 쓴다.
- 넣기: 입구 위로 운반 → 입구에서 내려놓기 → 앞턱에 차례로 가림 → 접촉 그림자 확정.
- 꺼내기: 안쪽에서 입구 높이까지 올리기 → 가구 위 운반 → 새 면에 내려놓기.
- 드래그 중인 물건은 운반 레이어에 그린다. 수납칸 앞턱을 통과해 집어내는 순간에 잘려서는 안 된다.
- 같은 면의 작은 밀림은 물건이 떠오르지 않는 미끄러짐이다. 책·물병을 고무처럼 늘이거나 크게 튀기지 않는다.
- 기본220~340ms에 이동 거리를 반영하되580ms를 넘지 않는다. 움직임 줄이기 설정에서는 즉시 확정한다.
- 초기화·맵 변경·blur·Escape·pointercancel·resize·탭 숨김은 활성 포인터와 애니메이션 예약을 함께 정리한다. 늦은 프레임이 이전 물건을 되살리면 실패다.
- 애니메이션은 저장하지 않으며 PNG는 확정된 물건만 그린다.

## 그림자와 가림

- 왼쪽 위 빛을 기준으로 물건 아래의 짧은 접촉 그림자와 오른쪽 아래 투사 그림자를 나눈다.
- 세워 둔 물건의 그림자는 밑면에서 시작한다. 운반 중에는 지지면에 붙은 그림자를 남기지 않는다.
- 그림자가 실제 면 밖 공중에 찍히지 않도록 지지면 또는 명시한 그림자 받는 면으로 제한한다.
- 책상 다리의 발은 고정 장애물이다. 다리 뒤의 물건은 가려지고, 다리 앞에 놓인 물건은 앞에 보인다.
- 수납칸의 앞턱·가방걸이의 돌기·휴지통 앞벽은 배경의 해당 부분을 복원하여 그린다. 무관한 배경 사각형으로 물건을 지우지 않는다.
- 먼지와 얼룩은 해당 지지면에서 물건보다 먼저 그린다. 물건 아래의 얼룩이 물건 표면 위로 비치면 실패다.

## 내 책상의 실제 측정값

- 바닥 지지면: (35,510)~(740,715). 뒤쪽 책상 다리에 종이가 걸려 보이지 않도록 초기 물건은 앞바닥에 둔다.
- 왼쪽 앞다리 발: (148,613)~(181,632), 고정 장애물. 다리 가림 깊이632.
- 가방 손잡이 접점: (821,318). 가방 그림의 같은 부분을 잡은 채 걸이↔바닥으로 옮겨도 튀지 않아야 한다.
- 휴지통 입구: 대략 y491~514. 안쪽 받침 면: y549~572, 확정 높이560. 들어 올리는 높이70으로 종이 전체가 앞턱 위에 나온 뒤 레이어를 바꾼다. 종이는 수납 후 앞벽 뒤로 완전히 가려지며 물건 ID와 목록은 유지한다.
- 실제 좌표·크기·가림 다각형의 원장은 `src/data/physical.ts`, `src/domain/placement.ts`다. 구현 계획의 E절 사각형은 제작 전 가이드다.

## 수납장 바구니의 앞면 구멍

- 원본1920×1440에서 바구니 앞면을 측정했다. `src/data/cabinet-occlusion.ts`에 플라스틱 앞면과32개 구멍을 따로 기록했다. 뒤쪽 벽의 구멍은 앞면 가림으로 취급하지 않는다.
- 렌더러는 앞면에서 구멍을 뺀 부분만 배경으로 복원한다. 물건은 구멍을 통해 보이고 플라스틱 살 뒤에서는 가려진다. 클릭 판정에도 같은 구멍을 사용한다.
- `?cabinet-review`는 기존 물병으로 가림을 시험하는 개발 화면이다. 학생용 수납장 맵을 열거나 물병을 체육 물품으로 분류한 것이 아니다.
- 좌·중·우 위치에서 각각6·2·6개 구멍을 통해 물건이 보였다. 실제 Canvas 픽셀을 가림 없는 그림·빈 배경과 비교해 구멍의 내부색과 살의 원본색을 확인했다. 정지 장면 검사이며 바구니 진입 동작의 완료 증거는 아니다.
- **진입 경로의 추가 조건:** 바구니가 수납장 안에 있어 위쪽 선반이 천장 역할을 한다. 물건을 위로 많이 들어 선반을 통과시키면 안 된다. 바구니 중앙의 낮은 앞턱을 통과할 때 물건 윗면이 선반 아래에 남는지 확인하고, 실제 공·줄넘기 입고 후 진입 경로를 정한다. 책상 휴지통의 수직 진입 높이를 복사하지 않는다.
- 가림 검수용 받침 좌표는 학습용 배치 검사에 연결하지 않았다. 실제 물건 크기·천장 여유·중앙 입구·안쪽 받침 면이 함께 통과해야 수납장 맵을 활성화한다.
