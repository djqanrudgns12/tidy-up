# 현재 구현 상태

이 파일은 `npm run handoff:sync`로 생성한다. 에셋 수량은 파일 검사 결과이며 시각 품질 승인을 뜻하지 않는다.

## 구현

- 전체 프로젝트 미완료. 목표: 9개 공간, 물건 72종, 추가 시점 22개, 배포 이미지 121개.
- 실측 데이터가 연결된 공간: 6개 (school-desk, classroom-cabinet, locker, library, home-desk, bedroom). 실제 활동 승인 범위는 검수 기록과 대조한다.
- 침실: 빈 매트리스 배경/별도 침구·옷 바구니 입구·42조합·브라우저 전체 활동/꺼내기/PNG/이어하기 검수 후 활성화.
- 공부 책상: 실제 자료 받침/서랍 입구·바닥·42조합 및 초기 각도 유지·브라우저 전체 활동/꺼내기/PNG/이어하기 검수 후 활성화.
- 도서관: 경사진 표지 진열대·책등 선반·반납 선반·42조합·브라우저 전체 흐름/책 꺼내기/PNG/이어하기 검수 후 활성화.
- 사물함: 책/파일 세우기·끌어 꺼내기·실측 선반/걸이·42조합·브라우저 전체 흐름·1984×848 결과 검수 후 활성화.
- 수납장: 상자3개 시점·실측 지지면·바구니 입구/천장·42조합·브라우저 전체 활동·PNG 생성·복원 검수 후 활성화. 실제 기기/교실 검수는 별도.
- 책상: 분류 → 추가 물건 0~3개 → 정리 → 청소 → 퀴즈 → PNG 흐름 구현. 작은 밀림, 두 겹 포개기, 가림, 접촉 그림자, 복원 구현.

최신 이동 인계와 미완성 코드 주의점: [데스크톱 인계](DESKTOP_HANDOFF_2026-09-16.md).
