# 배치 자유도와 안정성 개선

2026-09-16 밤 사용자 요청, 구현·검수 완료 시점 2026-09-17. 커밋·푸시·배포는 하지 않았다.

## 원인과 변경

- 종전에는 드롭 후보에 물건별 권장 구역 보너스 80px를 주고, 해당 면 전체에서 거리 제한 없이 빈자리를 찾았다. 사용자가 고른 상판·선반보다 정해 둔 칸이 우선되어 물건이 다른 곳으로 이동했다.
- 실제 입구/지지면을 직접 가리키면 그 면을 우선한다. 권장 구역 보너스를 제거하고, 직접 가리킨 면에 자리가 없을 때 다른 칸으로 자동 이동하지 않는다.
- 일반 선반·상판·보관칸은 실제 물건의 밑면, 폭, 깊이, 천장과 입구 여유로 판단한다. 평면 물건은 원래 각도를 먼저 시도하고, 맞지 않으면 0/90/-90도 방향을 확인한다. 별도 회전 버튼으로 정한 각도는 자동으로 바꾸지 않는다. 그림 축소나 다른 시점을 흉내 내는 변형은 없다.
- 같은 면의 자동 위치 보정은 지지점 기준 48 논리px 이내, 명시적 회전은 40px 이내다. 수납 입구→안쪽 받침점 이동과 걸이 접점 정규화는 이 거리와 별개다. 기존 물건의 위치는 바꾸지 않는다.
- 휴지통은 필요 없어진 종이(`paper-scrap`)만 받는다. 걸이·옷장 봉·우산꽂이의 기존 자세/물건 제한도 유지한다. 이 조건은 드롭, 이동 확정, 저장 복원에 공통 적용한다.
- ‘놓을 곳’은 권장 구역만 표시하지 않고 실제로 들어갈 수 있는 지지면을 표시한다. 현재 다른 물건이 차지하고 있어도 장소 자체는 목록에 유지한다. 목록으로 선택한 면이 장면 탭 처리에 전달되지 않던 문제도 수정했다.
- 일반 물건은 물리적으로 유효한 선반·상판에 놓았으면 정리된 것으로 본다. 바닥에 임시로 내려놓기는 계속 가능하며, 필요 없어진 종이는 휴지통에 넣어야 정리된 것으로 본다. 청소로 넘어가는 기존 자유는 유지한다.
