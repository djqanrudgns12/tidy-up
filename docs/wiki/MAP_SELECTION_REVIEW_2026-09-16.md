# 공간 선택 화면 정돈 — 2026-09-16

사용자 요청에 따라 공간 선택 화면의 여백·패널·카드 배열과 9개 공간 소개 문구를 수정했다. 기존 에셋과 MAP 액션, 공간별 사용 가능 여부는 유지한다.

- 제목·아이콘·안내·전체/학교/집 필터를 하나의 헤더 패널로 묶었다.
- 전체 9곳은 데스크톱 3×3, 학교 4곳은 2×2, 집 5곳은 3+2의 꽉 찬 행으로 표시한다.
- 601~1000px에서는 2열이며 홀수 마지막 카드는 전체 너비의 가로 카드다. 600px 이하는 그림과 설명을 나란히 놓은 1열이다.
- 썸네일은 원본 4:3 비율로 전체 그림을 보여 준다. 공간 종류·제목·소개를 구분하고 키보드 포커스와 선택 상태를 표시한다.
- 안내는 “내가 정리하고 싶은 공간을 선택해봅시다.”, 내 책상은 “책상 위에 있는 물건을 내 스타일대로 정리해봅시다.”로 반영했다. 나머지 8곳도 구체적인 활동을 담은 짧은 문장으로 수정했다.
