# 다음 작업과 완료 조건

기계 판독용 관계는 [work-tree.json](work-tree.json). 같은 ID를 사용한다. 현재는 사용자 요청으로 데스크톱 이동을 위해 중단했다. 재개 우선 작업은 **A3/M2(옷장)**이다. [최신 인계](DESKTOP_HANDOFF_2026-09-16.md)의 구체적 중단점을 먼저 확인한다. 단순한 파일 생성 수를 완료 기준으로 삼지 않는다.

## 작업 트리

```text
R0 인계/환경 확인 [새 데스크톱 원화57개 해시·문서·테스트·빌드 검증 완료]
└─ A1 기존 미반영27개 검수·수정·입고 완료
   ├─ A2 수납장 상자 낮은 정면3개 원화 반영 완료
   │  └─ V1 수납장 상자3개 시점·알파 크기·충돌·PNG 공통 연결 완료
   │     └─ M1 수납장 실측·수납 경로·42조합·전체 흐름 검수 완료
   └─ A3 나머지 원화 제작 및 검수
      └─ M2 나머지7개 공간을 한 공간씩 실측·검수
M1 + M2 → T1 검증 장면 썸네일 → Q1 전체 회귀·기기·교실 → D1 인계
```

## 지금 주의할 것

- 현재 생성 요청은 성공하지만 일부 출력의 투명도·시점이 기준에 못 미친다. 파일 입고와 시각 승인을 구분한다.
- 내 책상·수납장·사물함·도서관·공부 책상·침실 여섯 공간을 사용할 수 있다. 공부 책상은 서랍의 입구와 안쪽 바닥을 구분하고42조합·초기 각도 유지·브라우저 전체 활동·서랍 꺼내기/넣기·PNG·이어하기를 검수했다. 도서관은42조합·표지/책등/반납 자세·브라우저11개 조작·전체 수업 흐름·결과·이어하기까지 검수했다. 사물함도42조합·실제11개 조작·교과서 꺼내기/다시 넣기·전체 수업 흐름·PNG를 검수했다. 수납장은42조합·브라우저 실제11개 조작·공 드래그·청소·퀴즈·PNG 생성·이어하기까지 검수했다. 실제 기기와 교실 리허설은 Q1이다.
- 시점22개 중 수납장 상자3개와 사물함 책/파일3개를 연결했다. 알림장 책등은 원화 입고 완료다. 도서관 관련 책등7개를 추가 생성·검수했다. 걸린 시점3개는 생성되어 검수·수정·통합 대기다. 미생성 시점은 블록 상자1개와 신발4개, 총5개다. 사물함은 들고 이동하는 동안 실제 높이를 유지하며 투영 각도와 별도 원화의 기여도를 전환하고, 입구에 들어가기 전에 책을 완전히 세운다. 의류 등의 자세 전환은 남았다. 표지 그림을 좁혀 책등처럼 만들면 안 된다.
- 다른 공간에 책상의 소실점 `(518,-312)`나 휴지통 lift70을 그대로 복사하지 않는다.
- 사용자가 새 데스크톱에서 파일 복원 후 재개를 요청했다. 이전 데스크톱의 인계용 제작 중단은 종료했으며, 이후 다시 데스크톱 이동을 요청하여 중단했다. 다음 데스크톱에서 기존 미반영15개를 먼저 검수하고 필요한 수정과 새 시점5개를 생성한다.
