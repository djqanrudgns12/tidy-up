# 다음 작업과 완료 조건

기계 판독용 관계는 [work-tree.json](work-tree.json). 같은 ID를 사용한다. 현재 우선 작업은 **A1**이다. 단순한 파일 생성 수를 완료 기준으로 삼지 않는다.

## 작업 트리

```text
R0 인계/환경 확인 [이번 데스크톱 검증 완료, 새 컴퓨터에서 재확인]
└─ A1 이미 생성된 27개 미반영 원화 검수 및 알려진 5건 수정
   ├─ A2 수납장 상자 낮은 정면3개 (원본 디자인 유지)
   │  └─ V1 실제 시점 선택·알파 크기·충돌·PNG 공통 연결
   │     └─ M1 수납장 실측·수납 경로·42조합·전체 흐름
   └─ A3 나머지 원화 제작 및 검수
      └─ M2 나머지7개 공간을 한 공간씩 실측·검수
M1 + M2 → T1 검증 장면 썸네일 → Q1 전체 회귀·기기·교실 → D1 인계
```

## 지금 주의할 것

- 원화 생성은 더 이상 확인된 한도 때문에 막힌 상태가 아니다. 사용자 요청으로 이 컴퓨터의 제작 루프를 멈췄다.
- 첫 두 공간 중 내 책상만 사용할 수 있다. 수납장 바구니 가림 시험은 M1 완료가 아니다.
- 시점 목록22개는 정의만 있으며 모두 미생성·미연결이다. 표지 그림을 좁혀 책등처럼 만들면 안 된다.
- 다른 공간에 책상의 소실점 `(518,-312)`나 휴지통 lift70을 그대로 복사하지 않는다.
- A1과 독립적인 남은 원화 제작은 병행 가능하지만 생성 도구는 물건별로 호출한다. **최신 사용자 요청에 따라 이번 데스크톱에서는 새 생성 요청을 시작하지 않는다.**
- 현재 Vite/브라우저 프로세스·session ID는 인계 대상이 아니다. 새 환경에서 새로 실행한다.
