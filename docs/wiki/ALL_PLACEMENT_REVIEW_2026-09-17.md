2026-09-17 로컬 구현·검수 기록이다. 커밋·푸시·배포는 하지 않았다.

## 적용한 기준

- 사용자가 직접 가리킨 실제 지지면을 우선한다. 권장 구역은 안내에만 쓰고, 다른 칸으로 멀리 자동 이동시키지 않는다.
- 같은 지지면에서만 최대 48 논리px 범위로 가까운 빈자리를 찾는다. 기존 물건은 움직이지 않으며 벽·가구 밖, 물건 관통, 자동 줄 세우기를 허용하지 않는다.
- 휴지통은 휴지 더미만, 걸이는 걸 수 있는 물건만 받는다. 경사진 진열대는 책·자료 파일·클립보드처럼 실제로 기대어 둘 수 있는 평면 물건만 받는다.
- 책등 원화가 있는 선반에서는 `세워 꽂기`와 `눕혀 놓기`를 직접 선택한다. 좁아서 눕힐 수 없는 칸은 거부하며, 눕힌 책은 방향을 바꿀 수 있다.
- 책·자료 파일은 두 겹까지 포갠다. 윗물건 모서리의 돌출은 각 방향 6% 이내, 실제 지지 면적은 90% 이상이어야 한다. 아래 책이 세워져 있거나 이미 두 겹이면 더 쌓지 않는다.
- 오목한 바닥은 네 모서리뿐 아니라 footprint의 모든 변 구간을 검사해 가구 모서리를 가로지르는 배치를 거부한다.
- 같은 실제 상판을 여러 선택 영역이 공유해도 물건의 앞뒤 순서와 충돌을 함께 계산한다. 선반 앞턱 가림은 해당 지지면 전용 투명 레이어에서 처리해 다른 선반의 물건을 가로질러 지우지 않는다.

## 자세와 원화

- 모자, 챙이 넓은 모자, 베개, 쿠션에 낮은 앞면 시점 4개를 추가했다. 선반에서 높이와 두께가 보이며, 바닥·운반·선반에서 같은 시점을 유지한다.
- 딱풀은 기존 원화 자체가 세워진 모습이므로 upright 자세로 판정한다.
- 기존 저장의 위 물건 5종에 남아 있던 평면 회전값만 0도로 안전하게 이행한다. 좌표·진행 상태는 보존하고, 이행 뒤에도 전체 배치 검사를 통과하지 못하면 저장을 복원하지 않는다.
- 물건72종은 유지하고 추가 시점은 28개에서 32개, 배포 파일은 127개에서 131개가 되었다.

## 실제 브라우저 확인

- 9개 공간에서 각각 14개 물건의 기본·대안 배치 28개를 실제 원화로 렌더링해 선반 지지, 높이, 앞턱, 그림 크기를 확인했다.
- 사물함에서 교과서를 좁은 칸에 눕히려 할 때 공간 부족 안내와 원위치 유지가 동작했다.
- 도서관에서 과학책을 선반에 세움 → 같은 선반에서 눕힘 → 다시 세움으로 바꾸고, 자세에 맞춰 회전 버튼이 나타나고 사라지는 것을 확인했다.
- 저장 활동 이어하기가 기존 사물함 배치와 학생 정보를 복원하는 것을 확인했다.

## 사소한 후속 관찰

현재 공개수업을 막는 문제는 아니다. 다음 일반 개선 때만 검토한다.

- 매우 작은 책갈피·구두주걱은 실물 비율을 유지해 검수 시트에서 작게 보인다. 선택 목록과 실제 장면의 인지성을 학생 기기에서 확인한다.
- 좁은 선반에서 자세 변경이 실패할 때 안내는 정확하지만, 해당 물건 이름과 가능한 자세를 더 직접 말하는 문구로 다듬을 수 있다.
- 포개기는 의도치 않은 자동 정리를 피하려고 두 겹으로 제한했다. 세 겹 이상은 별도 상호작용 설계와 가림 검수가 생기기 전까지 늘리지 않는다.
- 252개 시각 검수는 데스크톱 로컬 브라우저 기준이다. 실제 학생 터치 기기, 교실 프로젝터, 공개수업 리허설, 게시 후 검수는 아직이다.
