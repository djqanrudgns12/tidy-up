# 정리 활동 통합·화면 검수 — 2026-09-16 저녁

## 물건 선택 강조·정리/청소 대상 분리 후속 개선

- 정리 정돈 단계의 장면에서는 먼지와 얼룩을 숨기고, 청소 단계에 들어갈 때만 청소 대상과 누르기 표식을 함께 표시한다. 결과 이미지의 정리 전/청소 후 비교는 기존처럼 먼지가 있는 전 장면과 청소된 후 장면을 유지한다.
- 장면에서 고른 물건의 실제 보이는 범위를 흰색 바깥선과 청록색 프레임으로 감싸고 체크 배지를 붙였다. 물건 그림 위를 색으로 덮지 않으며, 이동 중에는 프레임을 잠시 숨긴다. 작은 물건에서도 표시가 사라지지 않도록 화면 기준 최소 크기를 유지한다.
- `옮길 물건` 목록의 선택 카드에는 굵은 테두리·배경·체크 배지를 함께 사용한다. 선택 상태는 `aria-pressed`로도 유지한다.
- 정리 중 가구나 빈 곳처럼 옮길 수 없는 곳을 누르면 선택한 물건은 유지한 채, 누른 자리 가까이에 손바닥 아이콘과 `이곳은 옮기는 물건이 아니에요. 물건을 눌러 골라 주세요.`를 잠깐 표시한다. 숨겨진 먼지 자리 부근에는 `먼지는 정리를 마친 뒤 청소해요.`로 이유를 구분한다. 같은 안내는 상태 영역에도 남긴다.
- 선택 진입은 240ms, 불가능 피드백은 1.6초 안에 끝나며 `prefers-reduced-motion`에서는 확대·흔들림 없이 짧은 투명도 변화만 사용한다.
- 실제 브라우저에서 내 책상 정리 장면의 먼지 비노출, 책가방의 장면 프레임·체크와 목록 체크, 고정 가구 클릭 피드백, 청소 단계 전환 뒤 먼지 4곳 재노출을 확인했다. 390×844 CSS 뷰포트에서 청소 대상과 선택 프레임이 장면 폭 안에 유지됐고 브라우저 오류·경고는 0건이었다.
- `npm.cmd run typecheck`, `npm.cmd test` 16파일·80테스트, `npm.cmd run build`, `git diff --check`가 통과했다. 실제 학생 기기 터치·프로젝터 검수는 별도다.

## 결과 페이지·이미지 크게 보기 후속 개선

- 결과 화면을 완료 배지, 학생 이름 중심 제목, 완료한 3단계, 전후 비교 프레임, 저장 안내가 이어지는 기록 카드로 재구성했다. 정리 전·청소 후 사진은 화면의 중심을 유지한다.
- 저장 PNG를 2048×1024로 확장하고 두 장면은 각각 기존 960×720 크기로 유지했다. 학생 이름·공간 이름, 전후 라벨, 완료 메시지를 사진 바깥 여백에 추가했다.

## 회전 조작 위치 후속 개선

- 별도 `여기에 놓기` 버튼을 제거했다. 드래그가 어려운 경우에는 기존처럼 오른쪽 목록에서 물건과 놓을 곳을 고른 뒤 장면의 자리를 누를 수 있으며, 선택한 놓을 곳을 다시 누르면 탭 배치를 취소한다.
- 회전 가능한 물건을 선택하면 장면 바로 아래에 `선택한 물건`과 `방향 바꾸기`를 묶은 도구막대가 나타난다. `↶ 왼쪽 돌리기`, `↷ 오른쪽 돌리기`를 글자와 아이콘으로 함께 표시했다. 세움·걸기처럼 방향이 고정된 물건에는 버튼 대신 이유를 안내한다.
- 실제 브라우저에서 교과서를 책상 속 책칸에 놓은 뒤 왼쪽 회전이 장면에 반영되는 것을 확인했다. 390×844 CSS 뷰포트에서 각 회전 버튼은 154.5×48px였고 문서 가로 넘침은 없었다. 방향이 고정된 책가방 안내와 브라우저 오류·경고 0건도 확인했다.
- `npm.cmd test` 16파일·79테스트, `npm.cmd run build`, `npm.cmd run check:assets` 127/127이 통과했다. 실제 학생 기기 터치 검수는 아직 별도다.

## 최종 사용자 요청과 구현

- 물건 선택을 정리 정돈에 통합했다. 공간을 고르면 바로 정리를 시작하고 추가 물건 0~3개를 언제든 꺼내거나 다시 넣는다. 청소 이후에는 세트를 바꾸지 않는다.
- 기존 물건의 좌표·각도·쌓기 상태를 유지한다. 추가 물건은 실측된 등장 자리 중 비어 있는 곳을 먼저 사용하며, 모두 차 있으면 같은 지지면의 빈자리를 찾는다. 다른 물건을 자동으로 옮기지 않는다. 빈자리가 없으면 안내하고 추가하지 않는다.
- 위에 다른 물건이 얹힌 받침 물건은 제거하지 않는다. 윗물건을 먼저 옮겨야 한다. 3개 제한과 기본 물건 보호를 유지한다.
- 예전 setup 저장은 선택한 물건을 유지하며 organize 상태로 복원한다. ‘처음 화면으로’는 현재 진행을 저장한 채 랜딩으로 이동하고, ‘이어하기’로 같은 진행을 복원한다. 결과 PNG는 현재 세트의 초기 배치와 최종 배치를 비교한다.
- 물건 용도 설명과 원형 + 표시를 없앴다. 추가 물건은 장면 아래의 그림/이름 목록에 배치하고 꺼낸 상태는 테두리·배경·체크 문구로 표시한다.
- 캐릭터·학생 별명·공간 이름을 프로필 카드로 묶었다. 정리·청소·퀴즈·결과에 같은 프로필과 활동 설정 패널을 적용했다. 모바일에서는 프로필을 장면 위에 두고 패널을 한 열로 읽는다.
- 별도 물건 선택 시작과 물건 다시 고르기를 없앴다. 처음 화면으로·다른 공간 선택은 활동 설정의 테두리 있는 버튼으로 모았다. 다른 공간 선택의 기존 확인/취소 동작은 유지한다.
- 단계 표시와 첫 화면의 활동 안내는 정리 정돈 → 청소 → 마무리의 세 단계다.
