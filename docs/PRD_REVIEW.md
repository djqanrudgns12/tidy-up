# PRD 검토 기록: 정리 정돈과 청소를 실천해요

검토 이력: 2.0은2026-09-15 문서 단계 기록이다. 아래2.1의 최신 결정과 TASKS.md의 실제 진행 상태를 함께 읽는다.

## 2.1 추가 지시 반영 — 2026-09-16

사용자가 구현을 승인했고, 일정 단축보다 자연스러운 배치를 우선하도록 지시했다. 다음 기준으로 PRD·구현 계획·에셋 명세를 갱신했다.

- 중심점 판정을 실제 지지 다각형·물건 전체 경계·고정 장애물·물건 간 충돌 검사로 바꾼다. 상판과 바닥에서 물건이 뜨거나 가구를 관통하지 않아야 한다.
- 작은 겹침은 가까운 빈자리로 놓던 물건만 밀어 주고, 책은 안정적인 두 겹까지 허용한다. 화면과 PNG에 같은 깊이·가림·그림자를 사용한다.
- 수납 입구와 안쪽 면을 나눈다. 들어갈 때 앞턱 뒤로 내려가고 꺼낼 때 먼저 입구 위까지 올린다. 실제 걸이 접점, 물건 자세, 다른 시점 원화를 구분한다.
- 기존72종에 책등11·낮은 정면 상자4·의류/옷걸이3·신발4의 추가 시점을 더해 최종121파일로 확장한다. 원화112개와 파생 썸네일9개다.
- 전체 일정은98~148인시로 재산정한다. 대표 두 공간의41파일부터 검수하고, 다른 공간 확장은 지지면·수납 동작 통과 후 진행한다. 이미지 생성 한도 대기는 외부 대기 시간으로 구분한다.
- 작업 지침은 AGENTS.md와 PLACEMENT_REVIEW.md에 남긴다. 생성 완료·코드 검사·브라우저 검수·실기기 검수·수업 리허설의 완료 범위를 각각 기록한다.

현재 내 책상의 전체 활동과 배치 로직을 구현했다. 이미지 생성 사용량 제한으로 남은86개 원화와7개 썸네일은 대기 중이며, 다른8개 공간과22개 시점 연결은 완료되지 않았다. 이 문서는 전체 구현 완료 선언이 아니다.

## 1. 이번 개정의 결정

사용자가 **수업 완성도 우선, 일정 재산정**을 선택했다. 따라서 기존 1~2일 제약은 이번 확장 범위에 적용하지 않는다. 기능을 늘린 만큼 아트·상태 처리·실기기 검수를 포함해 80~120인시로 다시 산정했다. 구현·이미지 생성은 아직 승인되지 않았으므로 이번에는 지정한 Markdown 4개만 갱신한다.

| 생활 물건 | 같은 책·상자가 반복되어 공간별 쓰임이 약함 | 색상 변형을 별도 종류로 세지 않는 물건 72종. 모든 종류가 실제 맵에서 사용됨 |

튜토리얼의 네 이름은 **버려야 할 것 / 다른 사람의 도움을 받아야 할 것 / 지금 바로 해결해야 할 것 / 천천히 해결해도 되는 것**으로 유지한다. 긴급·중요 사분면으로 바꾸지 않는다. 지도서 속 역사 일화를 별도로 검증한 사실처럼 확장하지 않는다.

### 3.2 2022 개정 교육과정 확인

교육부 고시 제2022-33호 부칙에 따라 초등학교 5·6학년에는 **2026년 3월 1일**부터 2022 개정 교육과정이 적용된다. 2026학년도 5학년 수업 계획의 연계 근거로 사용한다. [교육부 고시 제2022-33호와 첨부 별책 10](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)

공식 파일은 **[별책 10] 실과(기술·가정)/정보과 교육과정**이다. NCIC 제공본은 총 222쪽이며, 핵심 성취기준은 **PDF 19쪽 / 인쇄 13쪽**에서 확인했다.

| 코드 | 이 활동과 연결되는 내용 | 한계 |
|---|---|---|
| [6실02-10] | 생활공간 관리의 필요성, 정리정돈과 청소 방법의 연습 | 쓰레기 처리 전체와 실제 생활 실천을 웹만으로 평가하지 않음 |
| [6실02-02] | 생활자원을 합리적으로 보관하고 활용하기 | 추가 물건의 개수나 가정 물건의 소유를 평가하지 않음 |

`6`은 6학년 전용 표시가 아니라 초등학교 5~6학년군 코드다. 같은 별책 인쇄 13~14쪽의 역할 편견 방지·생활자원 관리, 33~34쪽의 과정과 피드백·디지털 격차 고려도 검토했다. 특정 성별에 청소 역할을 맡기지 않고, 조작 속도를 학습 성과로 삼지 않는 설계로 연결했다. 이는 원문을 제품에 적용한 판단이다. [교육부 고시 제2022-33호와 첨부 별책 10](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)

출처 재확인 경로: 교육부 고시 게시물의 **붙임 2→별책 10**. NCIC 파일명은 `[별책10] 실과(기술가정)정보과 교육과정(제2022-33호).pdf`, 첨부 ID는 10004244다. NCIC 내려받기는 POST 방식이므로 검증되지 않은 직접 파일 주소를 링크로 만들지 않는다.

### 3.3 출처를 섞지 않는 기준

- 단원·차시 문구는 제공 자료와 사용자 지정에 따른다. 국가교육과정이 모든 교과서의 차시명을 동일하게 정한 것으로 쓰지 않는다.
- 제공 PDF를 ‘2022 개정 교과서’라고 소개하지 않는다.
- 9개 맵, 추가 선택, 구체적인 보관 장소, 카드·퀴즈, 수업 시간 배분은 제품 설계다.
- 앱의 성공 표시는 조작 단계의 완료다. 생활 습관이나 태도 달성의 증거로 바꾸지 않는다.
- 종이 조각 치우기는 분리배출 지도 전체를 대신하지 않는다. 다른 쓸 만한 물건을 쓰레기로 처리하게 하지 않는다.

## 4. 세 관점의 독립 검토와 통합

원 지시서의 병렬 검토 허용 범위에서 교육·학생 경험·기술 검토를 읽기 전용으로 진행했다. 검토자는 파일을 수정하지 않았고, 주 작성자가 결과를 통합했다.

| 관점 | 확인한 문제 | 반영 결정 |
|---|---|---|
| 교육 | 학년군 성취기준과 제공 자료 판본 혼동 | 코드·쪽수·시행일 확인, 출처 구분, 부분 연계로 표현 |
| 학생 경험 | 상자 반복, 실제 수납 구조 부족 | 72종 카탈로그와 9개 맵별 기본 8개·후보 6개 교차 대조 |
| 기술 | 정리 중 추가가 Before·완료·복원에 미치는 영향 | 시작 전에 선택 확정, 기본 8+추가n 모두 검사, 같은 세트로 초기화 |
| 공개수업 | 물건이 많으면 더 좋은 결과라는 인상 | 기본 선택 0개, 추가 보상 없음, 구두로 보관 이유 설명 |
| 작업량 | 확대된 아트와 기기 검수를 종전 일정에 누락 | 아트 포함 80~120인시, 내부 통과 기준을 둔 Phase 0~6 |

추가 개수는 처음에는 최대 2개와 3개를 비교했다. 일정 재산정이 승인된 점과 선택의 폭을 고려해 **3개**로 통일했다. 대신 후보는 현재 공간의 6종만 보여 주고 전체 72종 검색창은 만들지 않는다.

정리 도중 즉시 물건을 추가하는 안도 비교했다. 최종안은 **맵의 준비 화면에서 추가 물건이 나타나고, 정리 시작 후 학생이 직접 배치하는 방식**이다. 정리 중에는 ‘물건 다시 고르기’로 초기화 여부를 명시하고 선택 화면으로 돌아간다. 일반 초기화는 고른 물건을 유지한다.

## 6. 에셋·문장·운영의 핵심 검토

### 에셋

72종은 책 14, 필기·미술 15, 가방·휴대품 10, 의류·소품 13, 침구·공용 9, 놀이·운동·신발 8, 기타 3종이다. 물건의 모양과 쓰임이 다른 경우만 별도 종류로 센다. ‘대중적’이라는 기준은 생활 맥락과 인지 용이성을 위한 설계 판단이며 보유율 조사 결과가 아니다.

최종 배포 파일은 **99개 = 물건 72+배경 9+썸네일 9+캐릭터 4+도구 3+효과 2**다. 원화 90개와 파생 썸네일 9개를 구분한다. 기본 배치 72개, 추가 후보 배치 54개는 맵 데이터의 개체 수이며 원화 수와 다르다.

형태·크기·배경·보관 위치를 함께 검수한다. 가방을 작은 학용품칸에 넣거나 젖은 우산을 바로 수납하는 장면을 만들지 않는다. 옷·수건·우산·신발은 명시한 깨끗하고 마른 보관 상태로 그린다.

### 문장

PRD 18절은 실제 화면에 넣을 문구다. ‘생활 공간을 쾌적하게 관리하는 역량을 길러요’ 같은 목적어가 흐린 문장을 행동 지시로 쓰지 않는다. ‘필통을 옮겨 책상에서 쓸 자리를 남겨 주세요’처럼 눈앞의 물건과 행동을 연결한다.

검수는 ① 장면의 주체·물건이 분명한지 ② 지금 할 수 있는 행동인지 ③ 한 문장에 여러 지시를 겹쳤는지 ④ 모든 화면이 같은 권유문으로 끝나는지 ⑤ 실제 교사가 읽었을 때 설명을 덧붙여야 하는지 순서로 한다. 단어 금지 목록 검사만으로 문장 검수가 끝났다고 판단하지 않는다.

### 공개수업

학생의 조작을 중심에 두고 부모·교사는 결과의 미관보다 보관 이유와 청소 순서를 관찰하도록 안내한다. 수업안 예시는 PRD 7절에 둔다. 학부모용 계정·별도 대시보드·자동 채점은 추가하지 않는다. 실제 수업 기기에서 저장을 확인하기 전에는 수업 준비 완료로 보고하지 않는다.

## 8. 문서 완료와 후속 검증의 구분

이번에 확인한 것은 PDF 내용·페이지 이미지, 공식 교육과정, 기존 문서의 계약, 에셋 목록과 맵 참조, 일정 합계 및 문서 간 일치다. 앱 코드가 없으므로 typecheck·build·브라우저·실기기·배포 검증은 아직 하지 않았다.

문서에는 9개 맵, 72종, 기본 8+추가 0~3, 42조합/맵, 총 378조합, 99파일, 80~120인시를 동일하게 적용한다. 실제 아트가 입고된 뒤 좌표·표시 크기를 조정하는 일은 P0·P4의 예정된 검수다. 기능 범위를 다시 정하는 일과 구분하고, 조정 시 맵 revision과 관련 검수를 함께 갱신한다.

문서만으로 후속 수정이 전혀 없을 것을 보장하지 않는다. 구현자가 추가 기획 결정을 떠안지 않도록 선택·초기화·완료·저장·실패 처리까지 이번 안에서 정했다.


### 이번 문서의 정적 검사 결과

- PRD 34개 절, 구현 작업 영역 25개와 영역별 필수 항목 11개를 확인했다.
- 물건 ID 72개가 중복 없이 등록되고, 모두 맵의 기본 또는 추가 목록에서 사용됨을 대조했다.
- 세 문서에 반복된 9개 맵의 물건·허용 장소 표가 동일하다.
- 계획 데이터의 378개 선택 조합에서 초기 경계를 총 3,888회 계산했다. 계획한 그림 경계의 화면 이탈과 초기 외곽 사각형 겹침은 없었다.
- 위 계산은 문서의 초기 좌표·최대 표시 크기에 대한 검사다. 실제 그림 식별·보관 가능성·터치 사용성 검수는 P0~P5에서 진행한다.
- Phase 합계 80~120인시, 이미지 목표 5249KB·상한 8215KB, 최종 파일 99개 산식을 확인했다.
- 문서 링크·코드 블록·작업 공간 파일 목록을 확인했다. 지정 Markdown 4개와 원본 PDF 2개만 있으며 두 PDF 해시는 동일하다.
