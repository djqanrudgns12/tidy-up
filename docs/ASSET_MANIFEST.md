# 에셋 제작 명세: 정리 정돈과 청소를 실천해요

버전 2.1 · 2026-09-16 · **제작·적용 진행 중. 파일 존재와 시각 검수 완료를 구분한다.**

## 1. 제작 목표와 수량

학생이 그림을 보자마자 학교나 집에서 쓰는 물건을 떠올릴 수 있어야 한다. 용도를 모르는 상자를 반복하거나 색만 바꿔 종류를 늘리지 않는다. 책상 속 수납, 가방걸이, 반납 선반, 소품칸처럼 물건을 놓는 장소도 함께 설계한다.

- **이동 물건 72종:** 같은 아트를 여러 맵에서 재사용한다. 반납할 동화책처럼 상태가 다른 개체는 새 원화로 세지 않는다.
- **추가 시점 22개:** 같은 물건의 책장·선반·걸이 자세를 위한 원화다. 색만 바꾼 중복 이미지가 아니다.
- **배포 이미지 121파일:** 원화 112개와 파생 썸네일 9개.
- **맵 기본 개체 72개 + 추가 후보 정의 54개:** 한 번의 활동에서는 기본 8개와 추가 0~3개, 총 8~11개만 사용한다.
- 모든 72종이 9개 맵 중 적어도 한 곳에서 쓰인다. 구현하지 않을 장식 에셋을 수량에 포함하지 않는다.

이 목록의 ‘익숙함’은 보편적인 생활 장면을 위한 제품 설계 판단이다. 학생의 실제 보유율이나 인기 순위를 조사한 결과는 아니다. 브랜드·최신 기기·고가 가구·가족 구성·개인 방 보유를 선택 조건으로 삼지 않는다.

## 2. 공통 아트 디렉션

### 그림의 기준

정면에 가까운 시점에서 상판과 수납 내부가 조금 보이는 2D 생활 삽화로 통일한다. 가구는 단순하지만 책상 다리, 손잡이, 칸막이, 접힌 천처럼 쓰임을 알려 주는 부분을 남긴다. 원근이 강한 사진풍·아이소메트릭 게임 맵은 사용하지 않는다.

- 배경은 밝은 아이보리와 옅은 목재·회색 계열. 물건은 채도를 조금 높여 눈에 띄게 한다.
- 물건 윤곽은 최종 960×720 장면에서 약 1.5~2px로 보이는 선을 기준으로 맞춘다.
- 빛은 왼쪽 위다. 원화에는 물건 자체의 명암만 남기고, 바닥 접촉·투사 그림자는 실제 지지면과 이동 높이에 따라 런타임에서 그린다. 원화에 바닥 그림자를 붙여 중복시키지 않는다.
- 글자·상표·워터마크를 이미지로 생성하지 않는다. 책 제목과 장소 이름은 DOM/Canvas에서 작성한다.
- 모서리는 둥글게 표현하되 모든 물건을 장난감처럼 부풀리지 않는다.
- 사람 사진, 특정 교과서 표지·삽화 복제, 캐릭터 상품, 상표가 드러나는 게임·신발·가전은 제외한다.

### 생활 장면에서 확인할 점

가위는 날을 닫고 끝을 둥글게, 물병·풀은 뚜껑을 닫아 그린다. 신발·양말·장갑은 두 짝을 한 이미지로 묶는다. 우산과 우산 커버는 마른 상태다. 의류·침구·수건은 깨끗한 보관 상태로 통일한다. 실제 청소 도구와 개인 수건을 모양·이름으로 구별한다.

책·공책·알림장·자료 파일은 판형과 표지 구조로 구분한다. 놀이 상자는 말판·퍼즐 조각·블록·모양 카드가 보여야 한다. 쿠션·베개·이불·시트는 두께와 비율이 달라야 한다. 색을 제거한 축소 그림에서도 구별 가능한지 확인한다.

## 3. 배경과 고정 가구

## 4. 이동 물건의 파일·표시 규격

원화는 원칙적으로 512×512의 투명 WebP다. 중앙 정렬, 외곽 8% 이상 투명 여백, 실루엣 전체 보존을 지킨다. 긴 물건도 동일한 파일 캔버스에서 세로/가로 방향을 정해 제작하고 표시할 때 비율을 유지한다. 파일의 빈 여백과 실제 그림 경계는 입고 때 별도로 확인한다.

| 코드 | 논리 표시 경계 | 대표 물건 | 기본 회전 |
|---|---|---|---|
| B | 96×120 | 책·공책·자료 파일·클립보드 | 눕힘15도, 책등 세움은 고정 |
| S | 88×88 | 필통·지우개·작은 도구·접은 옷 | 지지면 안15도 |
| L | 120×44 | 연필·자·빗·리모컨·구두주걱 | 지지면 안15도 |
| X | 120×88 | 상자·침구·신발 한 켤레 | 눕힘15도, 정면 선반 자세는 고정 |
| T | 96×120 | 가방·긴바지·장화 | 눕힘15도, 세움·걸기는 고정 |
| U | 80×120 | 물병·우산·걸어 둔 겉옷 | 세움·걸기 고정 |

이 표는 제작 전 크기 분류다. 실제 크기는 가구와 원화의 비율을 보고 placement.ts에 정하며 수납 중 축소하지 않는다. 5절의 ‘회전 가능’은 제작 전 분류이고 실제 회전은 지지 자세를 따른다. 작은 물건은44 CSS px 보조 선택 영역과 DOM 목록을 제공한다. 학생에게 크기 조절을 제공하지 않는다.

기본 물건 경로는 **`assets/items/catalog/{ID}.webp`**, 추가 시점은 **`assets/items/views/{ID}--{view}.webp`**다. 물건마다 별도 맵 폴더를 만들지 않는다.

- 수건 원화(towel)는 사물함에서 ‘수건 / 손을 씻은 뒤 물기를 닦을 때’, 신발장에서 ‘신발용 마른 천 / 신발을 닦을 때’로 표시한다. 맵의 label과 purpose를 함께 덮어써 개인 수건을 신발용으로 안내하지 않는다.
- 도서관 b3은 ‘이야기 그림책’, b6·b7은 ‘반납할 동화책’, ‘반납할 과학책’으로 표시한다. 아트는 b1·b2와 공유한다.

- 추가 선택의 기본값은 0개다. 같은 후보를 중복으로 고르지 못하며 3개를 넘을 수 없다.
- 준비 화면에서 카드를 누르면 맵의 추가 대기 위치에 물건이 나타난다. 다시 누르면 선택을 해제한다.
- ‘이 물건으로 정리 시작’을 누르면 현재 세트를 확정하고 Before를 만든다. 이후 학생이 위치를 직접 정한다.
- 정리 도중 ‘물건 다시 고르기’는 진행을 초기화하는 별도 행동이다. 단순히 물건을 쓰레기통에 버려 제거하는 기능이 아니다.
- 72종 전체를 보여 주는 소환 창·검색·수집함·구매·잠금 해제는 만들지 않는다.

단위는 1KB=1,000바이트다. 목표·상한은 측정 결과가 아니라 입고 기준이다.

선택맵의 기본8+후보6은 최대14종이다. 추가 시점은 현재 맵의 지지 자세에 필요한 것만 읽는다. 기본 시점만 쓰는 내 책상의 예산은 목표889KB·상한1440KB다. 여러 시점을 쓰는 맵은 파일별 상한 합계가 아닌 실제 전송량으로1.5MB 목표를 검수하며, 초과 시 선택하지 않은 후보와 추가 시점을 늦게 읽는다. 전체 dist 목표는12MB다.

## 13. 좌표와 초기 장면 검수

제작 전 가이드는 [구현 계획 E절](IMPLEMENTATION_PLAN.md), 실제 측정값은 `src/data/physical.ts`다. [접촉 검수](PLACEMENT_REVIEW.md)의 수납·밀림·포개기 기준을 함께 따른다.

- 판정 사각형이 서랍 앞판·벽·빈 공중을 가리키지 않는다.
- 책장 라벨과 제목을 읽을 공간을 남긴다.
- 내 책상의 가방은 손잡이 안쪽을 실제 걸이의 받침에 맞춘다. 평면 위 자유 배치와 걸이의 고정 접점을 구분한다.
- 기본 물건 8+추가 대기 위치3은 맵마다 다르다. 추가 선택은 후보표 순서로 정렬해 S1~S3에 놓는다.
- 후보 6 중 0~3 선택은 맵당42조합, 전체 378조합이다. 정의·화면 경계·ID를 데이터로 검사한다.
- 가장 큰 추가 물건 3개와 작은 물건 3개 장면을 각각 확인한다. 실제 그림이 가려지는 문제와 확대된 히트 영역의 겹침을 구분한다.
- 378조합은 참조·개체·초기 경계를 데이터로 검사한다. 수납 가능성은 맵별로 큰 물건 3개·작은 물건 3개·같은 장소에 몰리는 대표 구성의 보관 예시를 실제 화면에서 확인한다. 모든 조합의 시각적 수납을 검증했다는 뜻이 아니며, 378장의 그림을 별도로 제작하지 않는다. 예시는 학생의 정답 좌표로 사용하지 않는다.
- 먼지 위치가 가구 위/바닥이라는 의미와 맞고, 청소 단계에서 접근할 수 있어야 한다.

## 14. 이미지 생성 프롬프트

다음은 제작 지시의 공통 틀이다. 실제 사용한26개 원화 프롬프트와 남은86개 원화 지시는 ASSET_PROMPTS.json에 기록했다. 현재 이미지 생성 사용량 제한으로 남은 제작은 대기 중이다. 프롬프트만으로 좌표·알파가 보장되었다고 보지 않고15절을 검사한다.

### 공통 스타일

> 한국 초등학교 5학년의 생활 수업에서 쓰는 2D 삽화. 정면에 가까우며 상판과 내부가 조금 보이는 일관된 시점. 밝은 아이보리 배경에 옅은 목재·회색 가구, 알아보기 쉬운 실물 비율. 왼쪽 위에서 오는 부드러운 빛, 짧은 그림자, 단정한 윤곽. 귀여운 장식보다 물건의 구조와 쓰임이 먼저 보이게. 글자, 상표, 로고, 워터마크, 사람, 캐릭터 상품 없음.

### 배경

> {맵의 배경·고정 가구}. 1920×1440, 가로4:3. 제공한 좌표 가이드의 수납 입구와 물건을 놓을 면을 따라 구성한다. {Z1~Z4 이름}가 실제 가구에서 구분되어 보이게 한다. 바닥 오른쪽에는 종이 치우기 통을 둔다. 정리할 작은 물건과 먼지는 그리지 않는다. 제목이나 라벨은 빈 자리로 남긴다. {맵별 위험}을 피하고 책상 아래나 수납장 내부가 가려지지 않게 한다.

### 개별 물건

> {카탈로그 이름} 한 개체. {카탈로그의 형태 특징}. {깨끗함·마름·닫힘·두 짝 등 상태}. 공통 배경과 같은 시점·빛·윤곽. 중심에 전체 실루엣, 바깥8% 투명 여백. 512×512 실제 투명 배경. 체커보드 무늬를 그리지 않는다. 브랜드·글자 없이 형태로 알아볼 수 있게. 손·다른 물건·방 배경·큰 바닥 그림자 없음.

### 캐릭터

> {토끼/곰/고양이/새} 안내 캐릭터 한 장. 편안한 표정, 정면에 가까운 작은 전신, 단정한 색 두세 개. 48px에서도 귀·얼굴·몸이 구분되게. 투명 배경 512×512. 말풍선·문자·복잡한 소품·반짝임 없음.

### 도구·효과

> {8절 파일의 그릴 내용}. 공통 스타일과 동일한 시점과 외곽선. 도구는512×512, 효과는256×256의 실제 투명 배경. 작은 크기에서 손걸레/개인 수건, 빗자루/바닥걸레가 구별되게 한다. 먼지와 얼룩은 서로 다른 형태와 색으로 표현하고 주변 가구는 그리지 않는다.

## 16. 개발 중 임시 표시

구현 승인 후 규칙 검증 단계에서는 이름이 적힌 임시 도형을 쓸 수 있다. 개발 화면에 임시 상태를 표시하고 공개수업 완료로 보고하지 않는다. 에셋 로딩이 실패한 최종 화면에서 도형으로 조용히 바꿔 진행시키지 않는다. 선택과 진행을 보존한 뒤 다시 불러오기 또는 물건 선택으로 돌아가는 경로를 제공한다.
